# Cypher-миграции Neo4j

Версионные forward-only миграции графа (issue #336, О4). Файлы именуются
`NNNN_<имя>.cypher` с монотонно растущим числовым префиксом и регистрируются в
[`../registry.ts`](../registry.ts) в массиве `neo4jMigrations`.

## Соглашения

- **Forward-only.** Уже зарелизенные файлы не редактируют — изменение схемы
  оформляют новой миграцией со следующим номером.
- **Один statement за вызов.** Neo4j `tx.run()` выполняет ровно один оператор,
  поэтому реестр разбивает файл по `;` и прогоняет операторы по очереди.
  Завершайте каждый оператор точкой с запятой.
- **Идемпотентность.** Используйте `IF NOT EXISTS` для constraint/index — раннер
  трекает применённые версии в узлах `(:SchemaMigration)`, но идемпотентный DDL
  упрощает ручные прогоны.
- **Комментарии.** Строки, начинающиеся с `//`, реестр игнорирует при разбиении.

## Сборка

`scripts/copy-db-assets.mjs` копирует `*.cypher` из этого каталога в
`dist/db/migrations/cypher/`, чтобы раннер мог читать их из собранного пакета.
